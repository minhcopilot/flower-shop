# Hoa Tươi Ia Pa

Website hoa tiếng Việt và trang quản trị local, phát triển từ Flora Bloom (Themixly, MIT).

Đọc [hướng dẫn sử dụng và vận hành](HUONG-DAN.md).

Chạy: `npm ci`, `npm run seed`, `npm run admin:setup`, `npm run build`, `npm start`.

Website: http://localhost:4317 — Quản trị: http://localhost:4317/admin.

Mã nguồn không chứa mật khẩu mặc định. Dữ liệu vận hành trong `data/`, bản sao lưu trong `backups/`; cả hai được bỏ qua bởi Git.

Nguồn gốc: https://github.com/themixlyweb/react-flower-shop-website-template — xem [LICENSE](LICENSE).
